# OCR 弃权候选的展示顺序（W8）

字段决策为 ambiguous / needs_review 时，图片候选按可信原图坐标从上到下、从左到右展示；缺少完整坐标时按冻结 OCR 文本位置展示，并明确记录 text 模式。缺少两种位置证据则保留原顺序、presentation 为未知。已选定字段保留原排序。字段和来源身份、事件 ID、角色、财务值及资格规则不变；同位置的历史纠错仍在原读数之后。

Web、Android 将实际收到的 presentation 随明确选择送回，服务端重新核验。旧客户端、版本不符或无法核验均记录 null，不能追认其展示。反馈同时记录既有同成员/来源/字段决策的历史曝光，接受历史建议仍沿用原防污染规则。没有查询到曝光不证明盲选，图上顺序也不意味着没有位置偏差。

验证涵盖坐标/文本反向排序、原件 ID、旧客户端及错误展示版本、实际金额与时间保存、历史建议撤回与来源失效、真实 Web 展示/点击/保存/回读；Android 覆盖 DTO、草稿恢复与请求携带展示元数据。没有新增学习表、默认金额、校准概率或原文纠正入口。质量增益和用户复核时间仍需独立数据。
